## Rules

1. **No hardcoded colors** — only `theme-*`, `text-primary`, `var(--*)`, `glass*`, `btn-primary`
2. **No hardcoded text** — all strings via `t("key")` from `useLanguage()`
3. **Hydration safe** — providers render null/skeleton until localStorage is read
4. **Responsive** — grids stack on mobile (`min-[400px]:grid-cols-*`), popovers go `fixed` on mobile
5. **Animations** — all use CSS classes from globals.css, all respect `prefers-reduced-motion`
6. **Accessibility** — `cursor-pointer` on interactives, `aria-label` on icon buttons, labels on inputs, `<fieldset>`/`<legend>` for grouped controls, `<progress>` for progress, `<output>` for live results, `aria-describedby` on tooltips
7. **Radix UI primitives** — `Dialog`, `DropdownMenu`, `Popover`, `Select`, `Tooltip`, `Tabs` and `Switch` come from `radix-ui`. Prefer a primitive over a hand-rolled overlay; style it with the theme classes, never a hardcoded color
