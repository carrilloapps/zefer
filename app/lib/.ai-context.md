# app/lib — Core Logic

All encryption, compression, device detection, and data handling logic. No UI, no React.

> **Scope.** This file is a directory-level orientation map, not a second
> specification. [`CLAUDE.md`](../../CLAUDE.md) is the source of truth for
> the binary format, the route table, the design system and the project
> rules; when the two disagree, `CLAUDE.md` wins and this file is wrong.

## Files

| File | Purpose | Key Exports |
|---|---|---|
| `crypto.ts` | AES-256-GCM encryption/decryption, PBKDF2 key derivation, benchmarking | `encrypt()`, `decrypt()`, `encryptBytes()`, `decryptBytes()`, `combineDualKeys()`, `hashAnswer()`, `benchmarkDevice()` |
| `zefer.ts` | ZEFB3 / ZEFR3 binary format encode/decode (legacy ZEFER3 / ZEFER2 decode only), all security checks | `encodeZefer()`, `decodeZefer()`, `parseFile()` |
| `chunked-crypto.ts` | 16 MB chunked encryption with a unique IV per chunk | `chunkedEncrypt()`, `chunkedDecrypt()`, `CHUNK_SIZE` |
| `compression.ts` | Gzip/Deflate via browser CompressionStream API | `compress()`, `decompress()` |
| `device.ts` | RAM/CPU/GPU detection, dynamic file size limits | `analyzeDevice()`, `formatBytes()` |
| `i18n.ts` | ~1,045 translation keys in es/en/pt | `t()`, `LOCALES`, `Locale`, `TranslationKey` |
| `ip.ts` | Public IP detection via ipify.org, IP allowlist check | `getClientIp()`, `parseIpList()`, `isIpAllowed()` |
| `notify.ts` | Toast notification helpers (Sonner) | `notify*()` |
| `passwords.ts` | Charsets (7 keygen modes), unbiased generation with advanced options, entropy and strength analysis, attack scenarios, compliance checks | `generateValue()`, `generateWithOptions()`, `MODES`, `analyzePassword()` |
| `preferences.ts` | Persisted user preferences via localStorage (`ttl`, `iterations`, `compression`, `inputMode`, `tab`, `keygenMode`, `keygenLength`, `keygenCount`, `keygenAdvanced`) | `usePreferences()` |
| `progress.ts` | Encryption/decryption progress tracking with device-calibrated timing | `createEncryptTracker()`, `createDecryptTracker()` |
| `seo.ts` | Centralized per-route metadata (Open Graph, Twitter, canonical, robots) | `pageMetadata()` |
| `useUrlParams.ts` | URL parameter parsing with long + short aliases; clears sensitive params | `useUrlParams()` |
| `file-handoff.ts` | Passes a file between the encrypt and decrypt forms without a re-upload | `setHandoffFile()`, `takeHandoffFile()` |

## Critical Patterns

- `crypto.ts` uses `Uint32Array` for uniform randomness in key generation
- `zefer.ts` payload format: `4-byte meta length (big-endian) + metadata JSON + raw content bytes`, encrypted as AES-256-GCM chunks (16 MB each, unique IV per chunk)
- Security metadata (expiration, question, IP allowlist, max attempts) lives **inside** the ciphertext; the public header carries only `iterations`, `compression`, `hint`, `note`, `mode`
- `device.ts` uses `performance.memory.jsHeapSizeLimit` (Chrome) → `navigator.deviceMemory` → cores heuristic (fallback chain)
- `i18n.ts` keys are typed — `TranslationKey` is a union of all literal key strings
- All functions are pure/async — no React dependencies
